> **ইতিহাসের মহান মনীষীদের এক টেবিলে বসান এবং তাদের আপনার প্রশ্ন নিয়ে বিতর্ক করতে দিন।**

Legend Talk ২-১০ জন ঐতিহাসিক বা সমকালীন চিন্তাবিদকে একটি বহু-রাউন্ড বিতর্কে একত্রিত করে। প্রতি রাউন্ডে প্রতিটি কণ্ঠ নিজস্ব কাঠামো থেকে যুক্তি দেয়; এরপর একজন সঞ্চালক মতপার্থক্যগুলো চিহ্নিত করেন এবং পরবর্তী রাউন্ড খোলেন। সক্রেটিস মুঙ্গারের অনুমানগুলোকে চাপে ফেলেন, আর নিৎশে তাদের দুজনকেই চ্যালেঞ্জ করেন।

**প্রবেশের তিনটি পথ:**

- **একটি প্রশ্ন করুন** — একটি বিষয় টাইপ করুন এবং AI ফলপ্রসূ টানাপোড়েনের জন্য তৈরি ৩-৫ জন চিন্তাবিদের প্যানেল সাজিয়ে দেয়।
- **টেবিল সাজান** — নিজে হাতে ২-১০ জন চিন্তাবিদ বেছে নিন, অথবা ৫ জনকে এলোমেলোভাবে নির্বাচন করুন।
- **একজন মনের সাথে পরামর্শ** — ১৬১ জন চিন্তাবিদের যেকোনো একজনের সাথে ১-১ আলাপ করুন, যেখানে প্রত্যেকে নিজস্ব কাঠামোর মধ্য দিয়ে যুক্তি দেয়, সাধারণ AI অভিনয় নয়।

**ডেমো:** [talk.newzone.top](https://talk.newzone.top) — ১৮ ভাষা · বিনামূল্যে · লোকাল-ফার্স্ট · সাইন-আপ ছাড়াই।

## কথোপকথন শুরু করুন

**স্বয়ংক্রিয় গোলটেবিল** — হোম পেজের ইনপুট বারে একটি বিষয় লিখুন। AI এমন ৩-৫ জন চিন্তাবিদ বেছে নেয় যাদের দৃষ্টিভঙ্গি সত্যিকারের সংঘর্ষে আসে এবং চরিত্র বাছাই ছাড়াই সঙ্গে সঙ্গে বিতর্ক শুরু করে।

**ম্যানুয়াল গোলটেবিল** — একটি দল গঠন করতে ২-১০টি চরিত্র কার্ডে **+** ক্লিক করুন। একটি ভাসমান বার আপনার নির্বাচনগুলো দেখায়:

- সরাতে একটি অবতারে ক্লিক করুন
- শুরু করতে **আলোচনা শুরু করুন**
- হুবহু দলটি একটি URL হিসেবে শেয়ার করতে **দলের লিঙ্ক কপি করুন**

অথবা ৫ জন এলোমেলো চিন্তাবিদ নিয়ে সঙ্গে সঙ্গে শুরু করতে **🎲 এলোমেলো** (উপরে-ডানে) চাপুন।

**ফিচার্ড টেমপ্লেট** — ৬টি বাছাইকৃত দল যাদের দৃষ্টিভঙ্গি সত্যিকারের সংঘর্ষে আসে (যেমন *AI & Tech*: Karpathy বনাম Ilya বনাম Feynman বনাম Taleb বনাম Paul Graham)। এক ক্লিকে শুরু, প্রতিটির সাথে ৩টি প্রস্তাবিত বিষয়।

**১-১ চ্যাট** — সেই চিন্তাবিদের কণ্ঠ ও কাঠামোয় ব্যক্তিগত কথোপকথনের জন্য যেকোনো চরিত্র কার্ডে **চ্যাট** ক্লিক করুন।

**বিষয় প্রস্তাব** — আপনার প্রথম বার্তার আগে, প্রতিটি মোড আপনাকে শুরু করতে বিষয় প্রস্তাব করে: প্রতি টেমপ্লেটে ৩টি বাছাইকৃত প্রশ্ন (সকল ১৮টি ভাষায়), অথবা ম্যানুয়াল দলে নির্বাচিত প্রতিটি চিন্তাবিদ থেকে ১টি প্রশ্ন (আপনি লোক যোগ বা সরালে আপডেট হয়)।

## আলোচনা পরিচালনা করুন

আপনি **সভাপতি** হিসেবে টেবিলের শীর্ষে বসেন — বিতর্ক আপনার শর্তেই চলে।

- **সঞ্চালক** — প্রতি রাউন্ডের পর একজন AI সঞ্চালক তা সংশ্লেষ করেন: দাবিগুলো ধারণা অনুযায়ী গোছান, রাউন্ডে অস্পর্শিত একটি দিক চিহ্নিত করেন, এবং পরবর্তীটির জন্য একটি উন্মুক্ত প্রশ্ন রাখেন।
- **বিতর্কের মাঝে পুনঃফোকাস** — গোলটেবিল চলাকালীন একটি বার্তা পাঠিয়ে তা পুনর্নির্দেশ করুন। স্বয়ংক্রিয়ভাবে চলার বদলে, একটি সম্পাদনাযোগ্য **ফোকাস কার্ড** আসে; এটি আগের যেকোনো ফোকাসের উপর জমা হয় যাতে পূর্বের নির্দেশনা হারিয়ে না যায়। এটি পরিমার্জন করুন, তারপর তার উপর ভিত্তি করে পরবর্তী রাউন্ডগুলো **শুরু করুন**।
- **প্রয়োগ ও পুনরায় চেষ্টা** — যেকোনো বার্তা সম্পাদনা করুন এবং সেই বিন্দু থেকে পুনরায় তৈরি করুন। সভাপতির নির্দেশনা একটি ফোকাস স্ন্যাপশট বহন করে, তাই পুনরায় চেষ্টা ঠিক সেই ফোকাস অবস্থা থেকে পুনর্গঠন করে যা বার্তা পাঠানোর সময় সক্রিয় ছিল।
- **রাউন্ড নির্ধারণ** — থামার আগে চিন্তাবিদরা কত রাউন্ড বিতর্ক করবেন তা বেছে নিন, এবং শেষ হলে আরও যোগ করতে **চালিয়ে যান**।
- যেকোনো সময় **অংশগ্রহণকারী যোগ বা সরান** — একটি ১-১ কে গোলটেবিলে রূপান্তর করুন, বা উল্টোটা।
- **থামান** — মাঝপথে জেনারেশন বাতিল করুন; যা ইতিমধ্যে লেখা হয়েছে তা রাখা হয়।
- **শাখা** — যেকোনো বার্তা থেকে একটি নতুন কথোপকথন তৈরি করুন, পূর্বের প্রসঙ্গ সাথে নিয়ে।

## সংরক্ষণ, অনুসন্ধান ও শেয়ার

- **সারসংক্ষেপ** — মূল দৃষ্টিভঙ্গি ও মতপার্থক্য বের করে এক ক্লিকে AI সারসংক্ষেপ।
- **অনুসন্ধান** — শিরোনাম, চিন্তাবিদের নাম, বা বার্তার বিষয়বস্তু দিয়ে সকল কথোপকথন জুড়ে যেকোনো কিছু খুঁজুন।
- **পছন্দের** — দ্রুত প্রবেশের জন্য আপনার সবচেয়ে বেশি ব্যবহৃত চিন্তাবিদদের তারকাচিহ্নিত করুন।
- **চ্যাট শেয়ার** — সম্পূর্ণ কথোপকথন সম্বলিত একটি URL তৈরি করুন।
- **রপ্তানি / আমদানি** — Markdown বা JSON হিসেবে সংরক্ষণ করুন এবং JSON থেকে পুনরুদ্ধার করুন (সেটিংসে), অথবা [json2card](https://github.com/rockbenben/json2card) দিয়ে শেয়ার কার্ড তৈরি করুন (সেটিংসে API এন্ডপয়েন্ট সেট করুন)।
- **সেটিংস সিঙ্ক** — URL দিয়ে আপনার সেটআপ অন্য ডিভাইসে নিয়ে যান; API কী AES-এনক্রিপ্টেড।

## চিন্তাবিদ, মডেল ও প্ল্যাটফর্ম

খ্যাতি অনুযায়ী সাজানো ১৫টি ক্ষেত্রে **১৬১ জন প্রিসেট চিন্তাবিদ** — তাৎক্ষণিকভাবে একটি কাস্টম চরিত্র তৈরি করতে যেকোনো নাম টাইপ করুন।

**মডেল** — **চিন্তার মাত্রা** নির্ধারণ করুন (বন্ধ / নিম্ন / মাঝারি / উচ্চ), একটি **কাস্টম মডেল ID** দিন, অথবা যেকোনো **OpenAI-সামঞ্জস্যপূর্ণ API** কাস্টম প্রদানকারী হিসেবে সংযুক্ত করুন। ডিফল্ট: DeepSeek V4 Flash।

**প্ল্যাটফর্ম** — ১৮ ভাষা · ডার্ক মোড · রেসপনসিভ · **লোকাল-ফার্স্ট** (IndexedDB + localStorage দ্বৈত-লেখন, WeChat ও সীমিত WebView-এ কাজ করে) · **শূন্য CDN** (ফন্ট স্ব-হোস্টেড ও বান্ডলড, তাই অফলাইনে ও ফায়ারওয়ালের পেছনে কাজ করে)।

## সরাসরি লিঙ্ক

একটি URL থেকে সরাসরি কথোপকথন শুরু করুন:

- **নাম দিয়ে:** `/#/chat?chars=苏格拉底,孔子` বা `/#/chat?chars=Socrates,Confucius`
- **ID দিয়ে:** `/#/chat?chars=socrates,confucius`
- **বিভাগ দিয়ে:** `/#/chat?category=philosophy` (সেই বিভাগের প্রতিটি চিন্তাবিদের গোলটেবিল, সর্বোচ্চ ১০ জন)
- **একক চ্যাট:** `/#/chat?chars=socrates`
- **কাস্টম নাম:** `/#/chat?chars=Ada Lovelace,Linus Torvalds` (অপরিচিত নাম কাস্টম চরিত্রে পরিণত হয়)

বিভাগসমূহ: `philosophy`, `strategy`, `business`, `finance`, `history`, `sociology`, `psychology`, `science`, `literature`, `art`, `economics`, `politics`, `technology`, `religion`, `education`।

**দলের লিঙ্ক কপি করুন** (অংশগ্রহণকারী বার) এবং **বিভাগের লিঙ্ক কপি করুন** (বিভাগ ফিল্টার) বোতামগুলো ইন্টারফেস থেকে এই URL তৈরি করে।

**ভাষা রাউটিং** — UI ভাষা নির্ধারণ করতে URL-এর শুরুতে একটি ভাষা যোগ করুন, যেমন `/#/ja/chat`, `/#/ko/chat?chars=socrates`, অথবা `?lang=zh` ব্যবহার করুন। সকল ১৮টি ভাষা সমর্থিত।

http://localhost:5173 খুলুন, সেটিংসে যান, আপনার API কী দিন, এবং চ্যাট শুরু করুন। CORS ত্রুটিতে পড়লে, অ্যাপটি এক ক্লিকে একটি পাবলিক প্রক্সি চালু করার প্রস্তাব দেয়।

## CORS প্রক্সি

কিছু প্রদানকারী সরাসরি ব্রাউজার অনুরোধ ব্লক করে। CORS প্রক্সি সেটিংসে প্রদানকারী অনুযায়ী কনফিগার করা হয় — এটি চালু করুন। ডিফল্টভাবে একটি পাবলিক প্রক্সি (`https://cors.api2026.workers.dev`) ব্যবহৃত হয়।

নিজের প্রক্সি চালাতে, এই কোড দিয়ে একটি [Cloudflare Worker](https://dash.cloudflare.com) ডিপ্লয় করুন:

<details>
<summary>Worker code</summary>

```javascript
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const targetUrl = url.pathname.slice(1) + url.search;
    if (!targetUrl || !targetUrl.startsWith('https://')) {
      return new Response('Usage: /https://target-api.com/path', { status: 400 });
    }
    if (request.method === 'OPTIONS') {
      return new Response(null, {
        headers: {
          'Access-Control-Allow-Origin': '*',
          'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS',
          'Access-Control-Allow-Headers': '*',
          'Access-Control-Max-Age': '86400',
        },
      });
    }
    const response = await fetch(targetUrl, {
      method: request.method,
      headers: request.headers,
      body: request.body,
    });
    const newResponse = new Response(response.body, response);
    newResponse.headers.set('Access-Control-Allow-Origin', '*');
    return newResponse;
  },
};
```
