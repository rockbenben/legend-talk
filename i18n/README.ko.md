> **역사상 가장 위대한 인물들을 한 테이블에 모아 당신의 질문을 토론하게 하세요.**

Legend Talk은 2~10명의 역사적·현대적 사상가를 다중 라운드 토론에 불러 모읍니다. 매 라운드마다 각각의 목소리가 자신만의 사고 틀로 논증하고, 이어서 주최자(주최)가 의견 대립을 정리하며 다음 라운드를 엽니다. 소크라테스가 멍거의 전제를 추궁하는 동안 니체는 두 사람 모두에게 도전합니다.

**세 가지 시작 방법:**

- **질문하기** — 토픽을 입력하면 AI가 생산적 긴장을 만들어내도록 구성된 3~5명의 사상가 패널을 조립합니다.
- **테이블 차리기** — 직접 2~10명의 사상가를 골라 담거나, 무작위로 5명을 뽑습니다.
- **한 사람과 상담하기** — 161명의 사상가 중 누구와도 1대1로 대화합니다. 각자 자신만의 사고 틀로 추론하며, 일반적인 AI 역할극이 아닙니다.

**데모:** [talk.newzone.top](https://talk.newzone.top) — 18개 언어 · 무료 · 로컬 우선 · 가입 불필요.

## 대화 시작하기

**자동 원탁** — 홈 페이지의 입력창에 토픽을 입력합니다. AI가 관점이 진정으로 충돌하는 3~5명의 사상가를 골라 캐릭터를 선택할 필요 없이 즉시 토론을 시작합니다.

**수동 원탁** — 캐릭터 카드의 **+**를 클릭해 2~10명의 라인업을 구성합니다. 플로팅 바에 선택한 인물이 표시됩니다.

- 아바타를 클릭하면 제거됩니다
- **토론 시작**으로 실행합니다
- **라인업 링크 복사**로 정확한 라인업을 URL로 공유합니다

또는 (우측 상단) **🎲 랜덤**을 눌러 무작위 5명의 사상가로 즉시 시작합니다.

**추천 템플릿** — 관점이 진정으로 충돌하는 6개의 엄선된 라인업 (예: *AI & Tech*: Karpathy vs Ilya vs Feynman vs Taleb vs Paul Graham). 한 번의 클릭으로 시작하며, 각 템플릿마다 3개의 추천 토픽이 있습니다.

**1대1 채팅** — 캐릭터 카드의 **채팅**을 클릭하면 그 사상가의 목소리와 사고 틀로 개인 대화를 나눕니다.

**추천 토픽** — 첫 메시지를 보내기 전에 모든 모드가 시작을 돕는 토픽을 제안합니다: 템플릿마다 엄선된 3개의 질문 (18개 언어 전체), 또는 수동 라인업에서 선택한 각 사상가마다 1개씩 뽑은 질문 (인물을 추가하거나 제거하면 업데이트됩니다).

## 토론 이끌기

당신은 **주석(主席)**으로서 테이블 상석에 앉아 토론을 당신의 방식대로 진행합니다.

- **주최자** — 각 라운드가 끝나면 AI 주최자가 라운드를 종합합니다: 주장들을 아이디어별로 묶고, 라운드가 다루지 않은 각도를 짚어내며, 다음 라운드를 위한 열린 질문을 던집니다.
- **토론 중 초점 전환** — 원탁 진행 중에 메시지를 보내 방향을 바꿉니다. 자동으로 진행되는 대신 편집 가능한 **초점 카드**가 나타나며, 이전의 모든 초점 위에 쌓여 앞선 방향 전환이 사라지지 않습니다. 다듬은 뒤 그것을 기준으로 다음 라운드를 **시작**합니다.
- **적용 및 재시도** — 어떤 메시지든 편집해 그 지점부터 재생성합니다. 주석의 방향 전환은 초점 스냅샷을 함께 담고 있어, 재시도 시 메시지를 보낼 당시 활성화되어 있던 정확한 초점 상태에서 다시 구성됩니다.
- **라운드 설정** — 사상가들이 멈추기 전까지 토론할 라운드 수를 정하고, 끝나면 **계속**으로 라운드를 추가합니다.
- **참가자 추가/제거** — 언제든지 가능합니다. 1대1을 원탁으로, 또는 그 반대로 바꿉니다.
- **중지** — 스트리밍 도중 생성을 취소합니다. 이미 작성된 내용은 보존됩니다.
- **브랜치** — 어떤 메시지에서든 이전 맥락을 가지고 새 대화로 분기합니다.

## 저장, 검색 및 공유

- **요약** — 핵심 관점과 의견 대립을 추출하는 원클릭 AI 요약.
- **검색** — 제목, 사상가 이름, 메시지 내용으로 모든 대화에서 무엇이든 찾습니다.
- **즐겨찾기** — 가장 자주 쓰는 사상가에 별표를 달아 빠르게 접근합니다.
- **채팅 공유** — 전체 대화가 담긴 URL을 생성합니다.
- **내보내기/가져오기** — Markdown 또는 JSON으로 저장하고 JSON에서 복원하거나(설정에서), [json2card](https://github.com/rockbenben/json2card)로 공유 카드를 생성합니다(설정에서 API 엔드포인트 지정).
- **설정 동기화** — URL로 설정을 다른 기기로 옮깁니다. API 키는 AES로 암호화됩니다.

## 사상가, 모델 및 플랫폼

**161명의 프리셋 사상가** — 15개 분야에 걸쳐 있으며 명성순으로 정렬됩니다. 아무 이름이나 입력하면 즉석에서 커스텀 캐릭터를 만들 수 있습니다.

**모델** — **사고 수준**(끔 / 낮음 / 중간 / 높음)을 설정하고, **커스텀 모델 ID**를 입력하거나, 모든 **OpenAI 호환 API**를 커스텀 제공업체로 연결합니다. 기본값: DeepSeek V4 Flash.

**플랫폼** — 18개 언어 · 다크 모드 · 반응형 · **로컬 우선**(IndexedDB + localStorage 이중 쓰기, WeChat 및 제한된 WebView에서 작동) · **CDN 제로**(폰트를 자체 호스팅·번들링하여 오프라인 및 방화벽 뒤에서도 작동).

## 딥 링크

URL로 직접 대화 시작:

- **이름으로:** `/#/chat?chars=苏格拉底,孔子` 또는 `/#/chat?chars=Socrates,Confucius`
- **ID로:** `/#/chat?chars=socrates,confucius`
- **카테고리로:** `/#/chat?category=philosophy` (해당 카테고리의 모든 사상가로 구성된 원탁, 최대 10명)
- **단일 채팅:** `/#/chat?chars=socrates`
- **커스텀 이름:** `/#/chat?chars=Ada Lovelace,Linus Torvalds` (인식되지 않는 이름은 커스텀 캐릭터가 됩니다)

카테고리: `philosophy`, `strategy`, `business`, `finance`, `history`, `sociology`, `psychology`, `science`, `literature`, `art`, `economics`, `politics`, `technology`, `religion`, `education`.

(참가자 바의) **라인업 링크 복사**와 (카테고리 필터의) **카테고리 링크 복사** 버튼이 이 URL들을 UI에서 생성합니다.

**언어 라우팅** — URL 앞에 언어 접두사를 붙여 UI 언어를 설정합니다. 예: `/#/ja/chat`, `/#/ko/chat?chars=socrates`, 또는 `?lang=zh` 사용. 18개 언어 모두 지원.

## CORS 프록시

일부 제공업체는 브라우저 직접 요청을 차단합니다. CORS 프록시는 설정에서 제공업체별로 구성하며, 켜기만 하면 됩니다. 기본적으로 공용 프록시(`https://cors.api2026.workers.dev`)가 사용됩니다.

직접 운영하려면 다음 코드로 [Cloudflare Worker](https://dash.cloudflare.com)를 배포하세요:

<details>
<summary>Worker code</summary>

```javascript
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const targetUrl = url.pathname.slice(1) + url.search;
    if (!targetUrl || !targetUrl.startsWith('https://')) {
      return new Response('Usage: /https://target-api.com/path', { status: 400 });
    }
    if (request.method === 'OPTIONS') {
      return new Response(null, {
        headers: {
          'Access-Control-Allow-Origin': '*',
          'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS',
          'Access-Control-Allow-Headers': '*',
          'Access-Control-Max-Age': '86400',
        },
      });
    }
    const response = await fetch(targetUrl, {
      method: request.method,
      headers: request.headers,
      body: request.body,
    });
    const newResponse = new Response(response.body, response);
    newResponse.headers.set('Access-Control-Allow-Origin', '*');
    return newResponse;
  },
};
```

</details>

## 개발

```
src/
  adapters/       # LLM API adapters (OpenAI-compatible, Anthropic)
  characters/     # Character presets and custom character generation
  components/     # React components
  hooks/          # useChat, useRoundtable
```

`dist/` 폴더를 빌드해 모든 정적 호스팅(Vercel, Netlify, GitHub Pages 등)에 배포하세요:
