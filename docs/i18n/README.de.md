> **Versammeln Sie die größten Denker der Geschichte an einem Tisch und lassen Sie sie über Ihre Frage debattieren.**

Legend Talk versammelt 2–10 historische oder zeitgenössische Denker zu einer mehrrundigen Debatte. In jeder Runde argumentiert jede Stimme aus ihrem eigenen Denkrahmen; ein Moderator ordnet anschließend die Meinungsverschiedenheiten und eröffnet die nächste Runde. Sokrates hinterfragt Mungers Annahmen, während Nietzsche beide herausfordert.

**Drei Wege hinein:**

- **Eine Frage stellen** — geben Sie ein Thema ein, und die KI stellt ein Panel aus 3–5 Denkern zusammen, das auf produktive Spannung ausgelegt ist.
- **Den Tisch decken** — wählen Sie 2–10 Denker selbst aus oder würfeln Sie 5 zufällig aus.
- **Einen Geist befragen** — gehen Sie 1-zu-1 mit einem von 161 Denkern, von denen jeder durch seinen eigenen Denkrahmen argumentiert, kein generisches KI-Rollenspiel.

**Demo:** [talk.newzone.top](https://talk.newzone.top) — 18 Sprachen · kostenlos · local-first · ohne Anmeldung.

## Ein Gespräch beginnen

**Automatischer Rundtisch** — geben Sie ein Thema in die Eingabeleiste auf der Startseite ein. Die KI wählt 3–5 Denker aus, deren Ansichten sich wirklich widersprechen, und startet die Debatte sofort, ohne dass Sie Charaktere auswählen müssen.

**Manueller Rundtisch** — klicken Sie auf **+** bei 2–10 Charakterkarten, um eine Aufstellung zu bilden. Eine schwebende Leiste zeigt Ihre Auswahl:

- Klicken Sie auf einen Avatar, um ihn zu entfernen
- **Diskussion starten**, um zu beginnen
- **Aufstellungslink kopieren**, um die genaue Aufstellung als URL zu teilen

Oder klicken Sie auf **🎲 Zufällig** (oben rechts), um sofort mit 5 zufälligen Denkern zu starten.

**Empfohlene Vorlagen** — 6 kuratierte Aufstellungen, deren Perspektiven wirklich aufeinanderprallen (z. B. _KI & Technik_: Karpathy vs. Ilya vs. Feynman vs. Taleb vs. Paul Graham). Ein Klick zum Start, jede mit 3 vorgeschlagenen Themen.

**1-zu-1-Chat** — klicken Sie auf **Chat** auf einer beliebigen Charakterkarte für ein privates Gespräch in der Stimme und im Denkrahmen dieses Denkers.

**Themenvorschläge** — bevor Sie Ihre erste Nachricht senden, schlägt jeder Modus Themen für den Einstieg vor: 3 kuratierte Fragen pro Vorlage (in allen 18 Sprachen) oder 1 Frage aus jedem ausgewählten Denker einer manuellen Aufstellung (aktualisiert sich beim Hinzufügen oder Entfernen von Personen).

## Die Diskussion lenken

Sie sitzen als **Vorsitzender** am Kopf des Tisches — die Debatte läuft zu Ihren Bedingungen.

- **Moderator** — nach jeder Runde fasst ein KI-Moderator sie zusammen: er gruppiert Aussagen nach Idee, benennt einen Aspekt, den die Runde unberührt gelassen hat, und stellt eine offene Frage für die nächste.
- **Mitten in der Debatte neu fokussieren** — senden Sie während eines Rundtischs eine Nachricht, um ihn umzulenken. Statt automatisch weiterzulaufen, erscheint eine bearbeitbare **Fokuskarte**; sie legt sich über jeden vorherigen Fokus, sodass frühere Lenkungen nicht verloren gehen. Verfeinern Sie sie und **starten** Sie dann die nächsten Runden, die darauf verankert sind.
- **Übernehmen & wiederholen** — bearbeiten Sie eine beliebige Nachricht und generieren Sie ab diesem Punkt neu. Lenkungen des Vorsitzenden tragen einen Fokus-Snapshot, sodass eine Wiederholung aus genau dem Fokuszustand neu aufbaut, der beim Senden der Nachricht aktiv war.
- **Runden festlegen** — wählen Sie, wie viele Runden die Denker debattieren, bevor pausiert wird, und **fortsetzen**, um nach Abschluss weitere hinzuzufügen.
- **Teilnehmer hinzufügen oder entfernen** jederzeit — verwandeln Sie ein 1-zu-1 in einen Rundtisch oder umgekehrt.
- **Stopp** — brechen Sie die Generierung mitten im Stream ab; was bereits geschrieben wurde, bleibt erhalten.
- **Verzweigen** — eröffnen Sie aus jeder Nachricht ein neues Gespräch, das den vorherigen Kontext mitnimmt.

## Speichern, suchen & teilen

- **Zusammenfassen** — KI-Zusammenfassung per Klick, die die Kernansichten und Meinungsverschiedenheiten herausarbeitet.
- **Suche** — finden Sie alles über alle Gespräche hinweg nach Titel, Denkername oder Nachrichteninhalt.
- **Favoriten** — markieren Sie Ihre meistgenutzten Denker für schnellen Zugriff.
- **Chat teilen** — generieren Sie eine URL, die das vollständige Gespräch enthält.
- **Exportieren / Importieren** — als Markdown oder JSON speichern und aus JSON wiederherstellen (in den Einstellungen) oder Teilkarten über [json2card](https://github.com/rockbenben/json2card) generieren (API-Endpunkt in den Einstellungen festlegen).
- **Einstellungssynchronisierung** — übertragen Sie Ihr Setup per URL auf ein anderes Gerät; API-Schlüssel sind AES-verschlüsselt.

## Schnellstart

```bash
npm install
npm run dev
```

Öffnen Sie http://localhost:5173, gehen Sie zu den Einstellungen, geben Sie Ihren API-Schlüssel ein und beginnen Sie zu chatten. Wenn Sie auf einen CORS-Fehler stoßen, bietet die App an, mit einem Klick einen öffentlichen Proxy zu aktivieren.

## Denker, Modelle & Plattform

**161 voreingestellte Denker** in 15 Bereichen, nach Bekanntheit sortiert — geben Sie einen beliebigen Namen ein, um spontan einen eigenen Charakter zu erstellen.

**Modelle** — legen Sie die **Denktiefe** fest (aus / niedrig / mittel / hoch), geben Sie eine **eigene Modell-ID** ein oder verbinden Sie eine beliebige **OpenAI-kompatible API** als eigenen Anbieter. Standard: DeepSeek V4 Flash. Die Denk-Steuerung erscheint nur bei Modellen, die das wirklich unterstützen; Anbieter ohne Aus-Schalter (Gemini, Grok, Groq, Cerebras, Moonshot) beschriften ihre unterste Stufe mit **Min** statt „aus“ – sie denkt weiter und wird weiter berechnet, „aus“ wäre gelogen.

**Plattform** — 18 Sprachen · Dunkler Modus · Responsive · **Local-first** (IndexedDB + localStorage Dual-Write, funktioniert in WeChat und eingeschränkten WebViews) · **Zero CDN** (Schriftarten selbst gehostet und gebündelt, funktioniert daher offline und hinter Firewalls).

## Deep Links

Starten Sie ein Gespräch direkt über eine URL:

- **Nach Name:** `/#/chat?chars=苏格拉底,孔子` oder `/#/chat?chars=Socrates,Confucius`
- **Nach ID:** `/#/chat?chars=socrates,confucius`
- **Nach Kategorie:** `/#/chat?category=philosophy` (Rundtisch jedes Denkers dieser Kategorie, auf 10 begrenzt)
- **Einzelchat:** `/#/chat?chars=socrates`
- **Eigene Namen:** `/#/chat?chars=Ada Lovelace,Linus Torvalds` (nicht erkannte Namen werden zu eigenen Charakteren)

Kategorien: `philosophy`, `strategy`, `business`, `finance`, `history`, `sociology`, `psychology`, `science`, `literature`, `art`, `economics`, `politics`, `technology`, `religion`, `education`.

Die Schaltflächen **Aufstellungslink kopieren** (Teilnehmerleiste) und **Kategorielink kopieren** (Kategoriefilter) generieren diese URLs über die Oberfläche.

**Sprachrouting** — stellen Sie der URL eine Sprache voran, um die UI-Sprache festzulegen, z. B. `/#/ja/chat`, `/#/ko/chat?chars=socrates`. Alle 18 Sprachen werden unterstützt.

## Unterstützte APIs

25 Anbieter von Haus aus — international, chinesisch und Aggregatoren:

- **International** — OpenAI · Anthropic · Google Gemini · xAI Grok · Mistral · Cohere
- **China** — DeepSeek · Qwen · Moonshot Kimi · Doubao · Xiaomi MiMo · Zhipu GLM · MiniMax · StepFun · Baidu Qianfan · Tencent TokenHub · Volcengine Coding Plan · Alibaba Bailian Coding Plan
- **Aggregatoren & Hosting** — OpenRouter · OpenCode Zen · Groq · Cerebras · SiliconFlow · AtlasCloud · NVIDIA NIM

Die aktuelle Modellliste jedes Anbieters steht in den Einstellungen — Modell-IDs ändern sich zu schnell, um sie hier zu spiegeln.

Qwen, MiMo, Moonshot, Zhipu, MiniMax und TokenHub bieten ihre regionalen Hosts per Klick. Darüber hinaus hat **jeder** Anbieter – auch Anthropic und Gemini – ein frei beschreibbares Endpunkt-Feld, denn welcher Upstream einen Browser blockiert, lässt sich nicht vorhersagen. Endpunkt und CORS-Proxy sind unabhängig: Du kannst auf dein eigenes Gateway zeigen und trotzdem direkt verbinden, oder den offiziellen Host über den Proxy nutzen.

Alle Anbieter akzeptieren eigene Modell-IDs. **Ein Modell lokal betreiben**: Die Option **Custom** nimmt jede OpenAI-kompatible Adresse an, mit Ein-Klick-Startadressen für LM Studio, Ollama, llama.cpp, LiteLLM, Together AI und Fireworks AI (jeweils mit Link zur eigenen Doku). Lokale Server brauchen keinen API-Schlüssel: dort _ist_ die Adresse die Zugangsberechtigung, das Schlüsselfeld bleibt optional.

## CORS-Proxy

Manche Anbieter senden keine CORS-Header, ein Browser erreicht sie also nicht direkt. Der Proxy ist ein Schalter pro Anbieter in den Einstellungen; standardmäßig wird ein öffentlicher (`https://cors.api2026.workers.dev`) verwendet.

**Für die Anbieter, die ihn brauchen, ist er bereits an** – OpenCode Zen, Tencent TokenHub, NVIDIA NIM und die beiden Coding-Plan-Einträge –, denn ohne ihn funktionieren sie schlicht nicht. Alles andere verbindet sich standardmäßig direkt.

> **Wissenswert, ob du ihn eingeschaltet hast oder ihn eingeschaltet vorgefunden hast.** Alles andere hier ist local-first; eine Anfrage über den Proxy ist es nicht. Dein API-Schlüssel und der vollständige Prompt laufen auf dem Weg zum Anbieter durch diesen Proxy. Entscheidend ist, was der Proxy damit macht, also konkret: Er leitet weiter und sonst nichts – der ganze Anfrageweg ist ein einziges durchreichendes `fetch`, ohne Logging und ohne jede Speicherung ([lies es selbst](../../scripts/cors-proxy-worker.js), es ist kurz). Außerdem leitet er nur an Hosts weiter, die in dieser Datei deklariert sind – kein offener Proxy, den jemand auf beliebige Ziele richten könnte.
>
> All das ändert nichts daran, dass die Anfrage durch eine Maschine läuft, die dieses Projekt betreibt. Wenn das für deinen Schlüssel zählt, betreibe deinen eigenen – etwa zwei Minuten.

Für einen eigenen: Deploye einen [Cloudflare Worker](https://dash.cloudflare.com) mit diesem Code und zeige in den Einstellungen darauf:

[`scripts/cors-proxy-worker.js`](../../scripts/cors-proxy-worker.js)

## Entwicklung

```text
src/
  adapters/       # LLM API adapters (OpenAI-compatible, plus native Anthropic and Gemini)
  characters/     # Character presets and custom character generation
  components/     # React components
  hooks/          # useChat, useRoundtable
  i18n/           # Internationalization
  pages/          # Routen-Komponenten: ChatPage, SettingsView, SharedView
  stores/         # Zustand state management
  utils/          # Prompt building, export, compression, storage
  types.ts        # Type definitions
```

**Stack:** React 19 · antd 6 (CSS-Variablen-Theme, tiefgreifend angepasst) · Vite · Tailwind CSS v4 · Zustand · i18next · React Router · TypeScript

| `npm run test`    | Tests ausführen                           |

## Deployment

Kompilieren Sie den `dist/`-Ordner und hosten Sie ihn auf einem beliebigen statischen Host (Vercel, Netlify, GitHub Pages, …):

```bash
npm run build
```

Das Routing ist hash-basiert (`/#/chat/...`, `/#/ja/chat/...`), sodass keine serverseitige Routing-Konfiguration nötig ist.
