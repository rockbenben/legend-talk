> **รวมนักคิดที่ยิ่งใหญ่ที่สุดในประวัติศาสตร์ไว้ที่โต๊ะเดียวกัน และให้พวกเขาถกเถียงปัญหาของคุณ**

Legend Talk เชิญนักคิดทางประวัติศาสตร์หรือร่วมสมัย 2-10 คนเข้าสู่การถกเถียงหลายรอบ ในแต่ละรอบ ทุกเสียงโต้แย้งจากกรอบความคิดของตนเอง จากนั้นผู้ดำเนินรายการจะสรุปประเด็นที่เห็นต่างและเปิดรอบถัดไป โสกราตีสตั้งคำถามกับสมมติฐานของมังเกอร์ ขณะที่นีตเชอท้าทายทั้งสองคน

**สามทางเข้าใช้งาน:**

- **ถามคำถาม** — พิมพ์หัวข้อ แล้ว AI จะรวบรวมคณะนักคิด 3-5 คนที่ออกแบบมาเพื่อสร้างความตึงเครียดอย่างสร้างสรรค์
- **จัดโต๊ะเอง** — เลือกนักคิด 2-10 คนด้วยตัวเอง หรือสุ่ม 5 คน
- **ปรึกษานักคิดคนเดียว** — สนทนา 1 ต่อ 1 กับนักคิดคนใดคนหนึ่งจาก 161 คน แต่ละคนใช้เหตุผลผ่านกรอบความคิดของตนเอง ไม่ใช่การสวมบทบาทแบบ AI ทั่วไป

**สาธิต:** [talk.newzone.top](https://talk.newzone.top) — 18 ภาษา · ฟรี · ท้องถิ่นก่อน · ไม่ต้องสมัครสมาชิก

## เริ่มการสนทนา

**โต๊ะกลมอัตโนมัติ** — ป้อนหัวข้อในแถบอินพุตบนหน้าหลัก AI จะเลือกนักคิด 3-5 คนที่มีมุมมองขัดแย้งกันอย่างแท้จริงและเริ่มการถกเถียงทันที โดยไม่ต้องเลือกตัวละครเอง

**โต๊ะกลมเลือกเอง** — คลิก **+** บนการ์ดตัวละคร 2-10 ใบเพื่อจัดทีม แถบลอยจะแสดงรายชื่อที่เลือก:

- คลิกที่อวาตาร์เพื่อลบออก
- **เริ่มการสนทนา** เพื่อเริ่มต้น
- **คัดลอกลิงก์รายชื่อ** เพื่อแชร์รายชื่อที่เลือกเป๊ะ ๆ เป็น URL

หรือกด **🎲 สุ่ม** (มุมขวาบน) เพื่อเริ่มทันทีด้วยนักคิดสุ่ม 5 คน

**เทมเพลตแนะนำ** — 6 รายชื่อคัดสรรที่มีมุมมองขัดแย้งกันอย่างแท้จริง (เช่น _AI & Tech_: Karpathy ปะทะ Ilya ปะทะ Feynman ปะทะ Taleb ปะทะ Paul Graham) คลิกเดียวเพื่อเริ่ม แต่ละเทมเพลตมาพร้อมหัวข้อแนะนำ 3 หัวข้อ

**แชท 1 ต่อ 1** — คลิก **แชท** บนการ์ดตัวละครใดก็ได้เพื่อสนทนาแบบส่วนตัวด้วยน้ำเสียงและกรอบความคิดของนักคิดคนนั้น

**หัวข้อแนะนำ** — ก่อนข้อความแรกของคุณ ทุกโหมดจะเสนอหัวข้อให้เริ่มต้น: 3 คำถามคัดสรรต่อเทมเพลต (ในทั้ง 18 ภาษา) หรือ 1 คำถามที่ดึงจากนักคิดแต่ละคนที่เลือกในรายชื่อเลือกเอง (อัปเดตเมื่อเพิ่มหรือลบคน)

## กำหนดทิศทางการสนทนา

คุณนั่งหัวโต๊ะในฐานะ **ประธาน** — การถกเถียงดำเนินไปตามเงื่อนไขของคุณ

- **ผู้ดำเนินรายการ** — หลังแต่ละรอบ ผู้ดำเนินรายการ AI จะสังเคราะห์: จัดกลุ่มข้อโต้แย้งตามแนวคิด ระบุมุมที่รอบนั้นยังไม่ได้แตะต้อง และตั้งคำถามปลายเปิดสำหรับรอบถัดไป
- **ปรับโฟกัสกลางการถกเถียง** — ส่งข้อความระหว่างโต๊ะกลมเพื่อเปลี่ยนทิศทาง แทนที่จะดำเนินอัตโนมัติ จะมี **การ์ดโฟกัส** ที่แก้ไขได้ปรากฏขึ้น มันซ้อนทับบนโฟกัสก่อนหน้าทุกอัน เพื่อไม่ให้การกำหนดทิศทางก่อนหน้าสูญหาย ปรับแต่งแล้วกด **เริ่ม** รอบถัดไปโดยยึดตามนั้น
- **ใช้และลองใหม่** — แก้ไขข้อความใดก็ได้แล้วสร้างใหม่จากจุดนั้น การกำหนดทิศทางของประธานจะพกสแนปช็อตโฟกัสไว้ ดังนั้นการลองใหม่จะสร้างขึ้นใหม่จากสถานะโฟกัสที่ใช้งานอยู่ตอนส่งข้อความนั้นเป๊ะ ๆ
- **ตั้งจำนวนรอบ** — เลือกว่านักคิดจะถกเถียงกี่รอบก่อนหยุดพัก และ **ดำเนินต่อ** เพื่อเพิ่มอีกเมื่อพวกเขาเสร็จ
- **เพิ่มหรือลบผู้เข้าร่วม** ได้ทุกเมื่อ — เปลี่ยนแชท 1 ต่อ 1 ให้เป็นโต๊ะกลม หรือกลับกัน
- **หยุด** — ยกเลิกการสร้างกลางคัน สิ่งที่เขียนไปแล้วจะถูกเก็บไว้
- **แยกสาขา** — แตกการสนทนาใหม่จากข้อความใดก็ได้ โดยพกบริบทก่อนหน้าไปด้วย

## บันทึก ค้นหา และแชร์

- **สรุป** — สรุปด้วย AI คลิกเดียว ดึงมุมมองหลักและประเด็นที่เห็นต่าง
- **ค้นหา** — ค้นหาอะไรก็ได้ในทุกการสนทนาตามชื่อเรื่อง ชื่อนักคิด หรือเนื้อหาข้อความ
- **รายการโปรด** — ติดดาวนักคิดที่ใช้บ่อยที่สุดเพื่อเข้าถึงได้รวดเร็ว
- **แชร์แชท** — สร้าง URL ที่มีการสนทนาทั้งหมด
- **ส่งออก / นำเข้า** — บันทึกเป็น Markdown หรือ JSON และกู้คืนจาก JSON (ในการตั้งค่า) หรือสร้างการ์ดแชร์ผ่าน [json2card](https://github.com/rockbenben/json2card) (กำหนดค่า API endpoint ในการตั้งค่า)
- **ซิงค์การตั้งค่า** — ย้ายการตั้งค่าของคุณไปยังอุปกรณ์อื่นผ่าน URL; API key ถูกเข้ารหัสด้วย AES

## นักคิด โมเดล และแพลตฟอร์ม

**นักคิดสำเร็จรูป 161 คน** ใน 15 สาขา เรียงตามความมีชื่อเสียง — พิมพ์ชื่อใดก็ได้เพื่อสร้างตัวละครกำหนดเองทันที

**โมเดล** — ตั้ง **ระดับการคิด** (ปิด / ต่ำ / กลาง / สูง) ป้อน **ID โมเดลกำหนดเอง** หรือเชื่อมต่อ **API ที่เข้ากันได้กับ OpenAI** ใด ๆ เป็นผู้ให้บริการกำหนดเอง ค่าเริ่มต้น: DeepSeek V4 Flash

**แพลตฟอร์ม** — 18 ภาษา · โหมดมืด · ตอบสนอง · **ท้องถิ่นก่อน** (เขียนคู่ IndexedDB + localStorage ทำงานได้ใน WeChat และ WebView ที่จำกัด) · **ไม่มี CDN** (ฟอนต์โฮสต์เองและรวมไว้ในแพ็กเกจ จึงทำงานได้แบบออฟไลน์และหลังไฟร์วอลล์)

## ลิงก์ตรง

เริ่มการสนทนาตรงจาก URL:

- **ตามชื่อ:** `/#/chat?chars=苏格拉底,孔子` หรือ `/#/chat?chars=Socrates,Confucius`
- **ตาม ID:** `/#/chat?chars=socrates,confucius`
- **ตามหมวดหมู่:** `/#/chat?category=philosophy` (โต๊ะกลมของนักคิดทุกคนในหมวดนั้น จำกัดสูงสุด 10 คน)
- **แชทเดี่ยว:** `/#/chat?chars=socrates`
- **ชื่อกำหนดเอง:** `/#/chat?chars=Ada Lovelace,Linus Torvalds` (ชื่อที่ไม่รู้จักจะกลายเป็นตัวละครกำหนดเอง)

หมวดหมู่: `philosophy`, `strategy`, `business`, `finance`, `history`, `sociology`, `psychology`, `science`, `literature`, `art`, `economics`, `politics`, `technology`, `religion`, `education`

ปุ่ม **คัดลอกลิงก์รายชื่อ** (แถบผู้เข้าร่วม) และ **คัดลอกลิงก์หมวดหมู่** (ตัวกรองหมวดหมู่) สร้าง URL เหล่านี้จากอินเทอร์เฟซ

**เส้นทางภาษา** — นำหน้า URL ด้วยภาษาเพื่อตั้งภาษาของอินเทอร์เฟซ เช่น `/#/ja/chat`, `/#/ko/chat?chars=socrates` หรือใช้ `?lang=zh` รองรับทั้ง 18 ภาษา

## CORS Proxy

บางผู้ให้บริการบล็อกคำขอตรงจากเบราว์เซอร์ CORS proxy กำหนดค่าต่อผู้ให้บริการในการตั้งค่า — เปิดสวิตช์ พร็อกซีสาธารณะ (`https://cors.api2026.workers.dev`) ถูกใช้เป็นค่าเริ่มต้น

> **ควรรู้ก่อนเปิดใช้** ส่วนอื่นทั้งหมดทำงานในเครื่องคุณ แต่คำขอที่ผ่านพร็อกซีไม่ใช่ — คีย์ API และพรอมป์ตทั้งหมดของคุณจะผ่านพร็อกซีนั้นก่อนถึงผู้ให้บริการ พร็อกซีเริ่มต้นดูแลโดยโปรเจกต์นี้ แต่พร็อกซีใด ๆ ก็เป็นเช่นนี้ เพราะนั่นคือสิ่งที่พร็อกซีทำ ถ้าคีย์นั้นสำคัญกับคุณ ให้สร้างของตัวเองด้วย Worker ด้านล่างแล้วชี้ในหน้าตั้งค่าไปที่นั่น ใช้เวลาราวสองนาที

หากต้องการรันพร็อกซีของคุณเอง ให้ deploy [Cloudflare Worker](https://dash.cloudflare.com) ด้วยโค้ดนี้:

<details>
<summary>Worker code</summary>

```javascript
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const targetUrl = url.pathname.slice(1) + url.search;
    if (!targetUrl || !targetUrl.startsWith("https://")) {
      return new Response("Usage: /https://target-api.com/path", { status: 400 });
    }
    if (request.method === "OPTIONS") {
      return new Response(null, {
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Access-Control-Allow-Methods": "GET, POST, PUT, DELETE, OPTIONS",
          "Access-Control-Allow-Headers": "*",
          "Access-Control-Max-Age": "86400",
        },
      });
    }
    const response = await fetch(targetUrl, {
      method: request.method,
      headers: request.headers,
      body: request.body,
    });
    const newResponse = new Response(response.body, response);
    newResponse.headers.set("Access-Control-Allow-Origin", "*");
    return newResponse;
  },
};
```
