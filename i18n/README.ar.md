> **اجمع أعظم عقول التاريخ حول طاولة واحدة ودعها تناقش مشكلتك.**

يجمع Legend Talk من 2 إلى 10 مفكرين تاريخيين أو معاصرين في نقاش متعدد الجولات. في كل جولة، يدافع كل صوت عن رأيه انطلاقاً من إطاره الفكري الخاص؛ ثم يرسم مُنسّق مواضع الخلاف ويفتح الجولة التالية. يضغط سقراط على مسلّمات مونغر بينما يتحدى نيتشه كليهما.

**ثلاث طرق للبدء:**

- **اطرح سؤالاً** — اكتب موضوعاً ويجمع الذكاء الاصطناعي لجنة من 3 إلى 5 مفكرين مصممة لإنتاج توتر مثمر.
- **جهّز الطاولة** — اختر بنفسك من 2 إلى 10 مفكرين، أو اختر 5 عشوائياً.
- **استشر عقلاً واحداً** — حاور بشكل فردي أياً من 161 مفكراً، كلٌّ يفكر عبر إطاره الخاص، لا مجرد تقمّص عام للذكاء الاصطناعي.

**عرض تجريبي:** [talk.newzone.top](https://talk.newzone.top) — 18 لغة · مجاني · محلي أولاً · بلا تسجيل.

## بدء محادثة

**طاولة مستديرة تلقائية** — أدخل موضوعاً في شريط الإدخال على الصفحة الرئيسية. يختار الذكاء الاصطناعي من 3 إلى 5 مفكرين تتعارض آراؤهم فعلاً ويبدأ النقاش فوراً، دون الحاجة لاختيار الشخصيات.

**طاولة مستديرة يدوية** — انقر على **+** في 2 إلى 10 بطاقات شخصيات لتكوين تشكيلة. يعرض شريط عائم اختياراتك:

- انقر على صورة رمزية لإزالتها
- **بدء النقاش** للانطلاق
- **نسخ رابط التشكيلة** لمشاركة التشكيلة نفسها كرابط URL

أو اضغط **🎲 عشوائي** (أعلى اليمين) للبدء فوراً بـ 5 مفكرين عشوائيين.

**قوالب مميزة** — 6 تشكيلات منتقاة تتصادم وجهات نظرها فعلاً (مثلاً *الذكاء الاصطناعي والتقنية*: كارباثي ضد إيليا ضد فاينمان ضد طالب ضد بول غراهام). نقرة واحدة للبدء، ولكل منها 3 مواضيع مقترحة.

**محادثة فردية** — انقر على **محادثة** في أي بطاقة شخصية لمحادثة خاصة بصوت ذلك المفكر وإطاره الفكري.

**اقتراحات المواضيع** — قبل رسالتك الأولى، يقترح كل وضع مواضيع لمساعدتك على البدء: 3 أسئلة منتقاة لكل قالب (بجميع اللغات الـ 18)، أو سؤال واحد مستمد من كل مفكر مختار في التشكيلة اليدوية (تتحدث عند إضافة أو إزالة الأشخاص).

## توجيه النقاش

تجلس على رأس الطاولة بصفتك **المضيف** — يجري النقاش وفق شروطك.

- **المُنسّق** — بعد كل جولة، يلخّصها مُنسّق بالذكاء الاصطناعي: يجمع الطروحات حسب الفكرة، ويسمّي زاوية لم تتطرق إليها الجولة، ويطرح سؤالاً مفتوحاً للجولة التالية.
- **إعادة التركيز أثناء النقاش** — أرسل رسالة أثناء الطاولة المستديرة لإعادة توجيهها. بدلاً من التشغيل التلقائي، تظهر **بطاقة تركيز** قابلة للتحرير؛ تتراكم فوق أي تركيز سابق فلا تضيع التوجيهات الأولى. حسّنها، ثم **ابدأ** الجولات التالية مرتكزاً عليها.
- **التطبيق وإعادة المحاولة** — حرّر أي رسالة وأعد التوليد من تلك النقطة. تحمل توجيهات المضيف لقطة تركيز، فتعيد المحاولة البناء من حالة التركيز الدقيقة التي كانت نشطة عند إرسال الرسالة.
- **تعيين الجولات** — اختر عدد الجولات التي يتناقش فيها المفكرون قبل التوقف، و**تابع** لإضافة المزيد عند انتهائهم.
- **إضافة أو إزالة المشاركين** في أي وقت — حوّل محادثة فردية إلى طاولة مستديرة، أو العكس.
- **إيقاف** — ألغِ التوليد أثناء البث؛ يُحفظ كل ما كُتب بالفعل.
- **تفريع** — افصل محادثة جديدة من أي رسالة، حاملةً السياق السابق معها.

## الحفظ والبحث والمشاركة

- **تلخيص** — ملخص بالذكاء الاصطناعي بنقرة واحدة يستخلص وجهات النظر الجوهرية ومواضع الخلاف.
- **بحث** — اعثر على أي شيء عبر كل المحادثات حسب العنوان أو اسم المفكر أو محتوى الرسالة.
- **المفضلة** — ضع نجمة على مفكريك الأكثر استخداماً للوصول السريع.
- **مشاركة المحادثة** — أنشئ رابط URL يحتوي المحادثة كاملة.
- **تصدير / استيراد** — احفظ بصيغة Markdown أو JSON واستعد من JSON (في الإعدادات)، أو أنشئ بطاقات مشاركة عبر [json2card](https://github.com/rockbenben/json2card) (عيّن نقطة نهاية API في الإعدادات).
- **مزامنة الإعدادات** — انقل إعداداتك إلى جهاز آخر عبر URL؛ مفاتيح API مشفّرة بمعيار AES.

## المفكرون والنماذج والمنصة

**161 مفكراً جاهزاً** عبر 15 مجالاً، مرتّبين حسب الشهرة — اكتب أي اسم لإنشاء شخصية مخصصة فوراً.

**النماذج** — عيّن **مستوى التفكير** (إيقاف / منخفض / متوسط / مرتفع)، أو أدخل **معرّف نموذج مخصص**، أو اربط أي **API متوافق مع OpenAI** كمزود مخصص. الافتراضي: DeepSeek V4 Flash.

**المنصة** — 18 لغة · وضع داكن · متجاوب · **محلي أولاً** (كتابة مزدوجة على IndexedDB + localStorage، يعمل في WeChat ومتصفحات WebView المقيّدة) · **بلا CDN** (الخطوط مستضافة ذاتياً ومضمّنة، فيعمل دون اتصال وخلف جدران الحماية).

## روابط مباشرة

ابدأ محادثة مباشرة من رابط URL:

- **بالاسم:** `/#/chat?chars=苏格拉底,孔子` أو `/#/chat?chars=Socrates,Confucius`
- **بالمعرف:** `/#/chat?chars=socrates,confucius`
- **بالفئة:** `/#/chat?category=philosophy` (طاولة مستديرة لكل مفكر في تلك الفئة، بحد أقصى 10)
- **محادثة فردية:** `/#/chat?chars=socrates`
- **أسماء مخصصة:** `/#/chat?chars=Ada Lovelace,Linus Torvalds` (الأسماء غير المعروفة تصبح شخصيات مخصصة)

الفئات: `philosophy`, `strategy`, `business`, `finance`, `history`, `sociology`, `psychology`, `science`, `literature`, `art`, `economics`, `politics`, `technology`, `religion`, `education`.

يولّد زرّا **نسخ رابط التشكيلة** (شريط المشاركين) و**نسخ رابط الفئة** (مرشّح الفئة) هذه الروابط من الواجهة.

**توجيه اللغة** — أضف بادئة لغة إلى الرابط لتعيين لغة الواجهة، مثلاً `/#/ja/chat`، `/#/ko/chat?chars=socrates`، أو استخدم `?lang=zh`. جميع اللغات الـ 18 مدعومة.

## بداية سريعة

```bash
npm install
npm run dev
```

افتح http://localhost:5173، اذهب إلى الإعدادات، أدخل مفتاح API الخاص بك، وابدأ المحادثة. إذا واجهت خطأ CORS، يعرض التطبيق تفعيل وكيل عام بنقرة واحدة.

## وكيل CORS

بعض المزودين يحظرون طلبات المتصفح المباشرة. يُهيّأ وكيل CORS لكل مزود في الإعدادات — فعّله. يُستخدم وكيل عام (`https://cors.api2026.workers.dev`) افتراضياً.

لتشغيل وكيلك الخاص، انشر [Cloudflare Worker](https://dash.cloudflare.com) بهذا الكود:

<details>
<summary>Worker code</summary>

```javascript
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const targetUrl = url.pathname.slice(1) + url.search;
    if (!targetUrl || !targetUrl.startsWith('https://')) {
      return new Response('Usage: /https://target-api.com/path', { status: 400 });
    }
    if (request.method === 'OPTIONS') {
      return new Response(null, {
        headers: {
          'Access-Control-Allow-Origin': '*',
          'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS',
          'Access-Control-Allow-Headers': '*',
          'Access-Control-Max-Age': '86400',
        },
      });
    }
    const response = await fetch(targetUrl, {
      method: request.method,
      headers: request.headers,
      body: request.body,
    });
    const newResponse = new Response(response.body, response);
    newResponse.headers.set('Access-Control-Allow-Origin', '*');
    return newResponse;
  },
};
```

## التطوير
