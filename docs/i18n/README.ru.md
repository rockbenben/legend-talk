> **Соберите величайших мыслителей истории за одним столом и позвольте им обсудить ваш вопрос.**

Legend Talk собирает от 2 до 10 исторических или современных мыслителей в многораундовые дебаты. В каждом раунде каждый голос отстаивает свою точку зрения, исходя из собственной системы взглядов; затем модератор очерчивает разногласия и открывает следующий раунд. Сократ испытывает на прочность допущения Мангера, пока Ницше бросает вызов им обоим.

**Три способа начать:**

- **Задайте вопрос** — введите тему, и AI соберёт панель из 3-5 мыслителей, выстроенную ради продуктивного напряжения.
- **Накройте стол сами** — лично выберите от 2 до 10 мыслителей или соберите 5 случайных.
- **Обратитесь к одному уму** — поговорите один на один с любым из 161 мыслителя, каждый из которых рассуждает в рамках собственной системы взглядов, а не как обобщённый AI-ролеплей.

**Демо:** [talk.newzone.top](https://talk.newzone.top) — 18 языков · бесплатно · локальный приоритет · без регистрации.

## Начало беседы

**Автоматический круглый стол** — введите тему в строке ввода на главной странице. AI выберет 3-5 мыслителей, чьи взгляды действительно расходятся, и немедленно начнёт дебаты — выбирать персонажей не нужно.

**Ручной круглый стол** — нажмите **+** на 2-10 карточках персонажей, чтобы собрать состав. Плавающая панель показывает ваш выбор:

- Нажмите на аватар, чтобы удалить его
- **Начать обсуждение**, чтобы запустить
- **Копировать ссылку на состав**, чтобы поделиться точным составом в виде URL

Или нажмите **🎲 Случайный** (вверху справа), чтобы мгновенно начать с 5 случайными мыслителями.

**Готовые шаблоны** — 6 подобранных составов, чьи взгляды действительно сталкиваются (например, _AI и технологии_: Карпаты против Ильи против Фейнмана против Талеба против Пола Грэма). Один клик для старта, у каждого по 3 предложенные темы.

**Чат 1 на 1** — нажмите **Чат** на любой карточке персонажа, чтобы провести приватную беседу голосом и в системе взглядов этого мыслителя.

**Рекомендуемые темы** — перед вашим первым сообщением каждый режим предлагает темы для начала: 3 подобранных вопроса на шаблон (на всех 18 языках) или 1 вопрос от каждого выбранного мыслителя в ручном составе (обновляется по мере добавления или удаления участников).

## Управление обсуждением

Вы сидите во главе стола как **председатель** — дебаты идут на ваших условиях.

- **Модератор** — после каждого раунда AI-модератор подводит итог: группирует утверждения по идеям, называет угол зрения, который раунд оставил без внимания, и ставит открытый вопрос для следующего.
- **Смена фокуса посреди дебатов** — отправьте сообщение во время круглого стола, чтобы перенаправить его. Вместо автоматического запуска появляется редактируемая **карточка фокуса**; она накладывается поверх любого предыдущего фокуса, так что ранние корректировки не теряются. Уточните её, затем нажмите **Старт** для следующих раундов, опирающихся на неё.
- **Применить и перезапустить** — отредактируйте любое сообщение и сгенерируйте заново с этого момента. Корректировки председателя несут снимок фокуса, поэтому перезапуск восстанавливается из точного состояния фокуса, который был активен в момент отправки сообщения.
- **Настройка раундов** — выберите, сколько раундов мыслители будут вести дебаты до паузы, и нажмите **Продолжить**, чтобы добавить ещё, когда они закончат.
- **Добавляйте или удаляйте участников** в любой момент — превратите беседу 1 на 1 в круглый стол или наоборот.
- **Стоп** — отмените генерацию на полпути; всё, что уже было написано, сохраняется.
- **Ветвление** — создайте новую беседу из любого сообщения, перенося в неё предшествующий контекст.

## Сохранение, поиск и обмен

- **Итоги** — AI-резюме в один клик, извлекающее ключевые точки зрения и разногласия.
- **Поиск** — найдите что угодно по всем беседам: по заголовку, имени мыслителя или содержимому сообщений.
- **Избранное** — отметьте звёздочкой самых востребованных мыслителей для быстрого доступа.
- **Поделиться беседой** — сгенерируйте URL, содержащий полную беседу.
- **Экспорт / Импорт** — сохраните в Markdown или JSON и восстановите из JSON (в Настройках) или создавайте карточки для обмена через [json2card](https://github.com/rockbenben/json2card) (укажите адрес API в Настройках).
- **Синхронизация настроек** — перенесите вашу конфигурацию на другое устройство по URL; API-ключи шифруются по AES.

## Мыслители, модели и платформа

**161 готовый мыслитель** в 15 областях, отсортированных по известности — введите любое имя, чтобы на лету создать своего персонажа.

**Модели** — задайте **глубину размышлений** (выкл. / низкая / средняя / высокая), введите **свой ID модели** или подключите любой **OpenAI-совместимый API** как своего провайдера. По умолчанию: DeepSeek V4 Flash.

**Платформа** — 18 языков · тёмная тема · адаптивность · **локальный приоритет** (двойная запись в IndexedDB + localStorage, работает в WeChat и ограниченных WebView) · **без CDN** (шрифты размещены локально и встроены, поэтому работает офлайн и за брандмауэрами).

## Прямые ссылки

Начните беседу прямо из URL:

- **По имени:** `/#/chat?chars=苏格拉底,孔子` или `/#/chat?chars=Socrates,Confucius`
- **По ID:** `/#/chat?chars=socrates,confucius`
- **По категории:** `/#/chat?category=philosophy` (круглый стол из всех мыслителей этой категории, не более 10)
- **Одиночный чат:** `/#/chat?chars=socrates`
- **Свои имена:** `/#/chat?chars=Ada Lovelace,Linus Torvalds` (нераспознанные имена становятся своими персонажами)

Категории: `philosophy`, `strategy`, `business`, `finance`, `history`, `sociology`, `psychology`, `science`, `literature`, `art`, `economics`, `politics`, `technology`, `religion`, `education`.

Кнопки **Копировать ссылку на состав** (панель участников) и **Копировать ссылку на категорию** (фильтр категорий) генерируют эти URL из интерфейса.

**Языковая маршрутизация** — добавьте префикс языка к URL, чтобы задать язык интерфейса, например `/#/ja/chat`, `/#/ko/chat?chars=socrates`, или используйте `?lang=zh`. Поддерживаются все 18 языков.

## CORS-прокси

Некоторые провайдеры блокируют прямые запросы из браузера. CORS-прокси настраивается для каждого провайдера в Настройках — просто включите его. По умолчанию используется публичный прокси (`https://cors.api2026.workers.dev`).

> **Стоит знать перед включением.** Всё остальное здесь работает локально, но запрос через прокси — нет: ваш API-ключ и полный промпт проходят через этот прокси по пути к провайдеру. Прокси по умолчанию держит этот проект, но с любым прокси то же самое — в этом и есть его суть. Если ключ вам важен, поднимите свой с помощью Worker ниже и укажите его в настройках; это занимает пару минут.

Чтобы запустить собственный, разверните [Cloudflare Worker](https://dash.cloudflare.com) с этим кодом:

<summary>Worker code</summary>

```javascript
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const targetUrl = url.pathname.slice(1) + url.search;
    if (!targetUrl || !targetUrl.startsWith("https://")) {
      return new Response("Usage: /https://target-api.com/path", { status: 400 });
    }
    if (request.method === "OPTIONS") {
      return new Response(null, {
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Access-Control-Allow-Methods": "GET, POST, PUT, DELETE, OPTIONS",
          "Access-Control-Allow-Headers": "*",
          "Access-Control-Max-Age": "86400",
        },
      });
    }
    const response = await fetch(targetUrl, {
      method: request.method,
      headers: request.headers,
      body: request.body,
    });
    const newResponse = new Response(response.body, response);
    newResponse.headers.set("Access-Control-Allow-Origin", "*");
    return newResponse;
  },
};
```

## Разработка

```text
src/
  adapters/       # LLM API adapters (OpenAI-compatible, Anthropic)
  characters/     # Character presets and custom character generation
  components/     # React components
  hooks/          # useChat, useRoundtable
  i18n/           # Internationalization
  stores/         # Zustand state management
  utils/          # Prompt building, export, compression, storage
  types.ts        # Type definitions
```

**Стек:** React 19 · antd 6 (тема на CSS-переменных, глубоко кастомизированная) · Vite · Tailwind CSS v4 · Zustand · i18next · React Router · TypeScript

## Развёртывание

Соберите и разместите папку `dist/` на любом статическом хостинге (Vercel, Netlify, GitHub Pages, …):

```bash
npm run build
```

Маршрутизация основана на хэше (`/#/chat/...`, `/#/ja/chat/...`), поэтому серверная настройка маршрутизации не нужна.
